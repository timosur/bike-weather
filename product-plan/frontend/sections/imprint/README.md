# Imprint

## Overview

Legally required provider identification pursuant to SS 5 TMG / SS 18 MStV. Contains the operator's name, address, contact details, and liability notices. Plain, readable text page focused on legal compliance.

## User Flows

1. **Navigate:** User navigates to the imprint via the footer link.
2. **Read:** User finds all legally required information.

## Components Provided

### `Imprint`

The complete imprint page component. Renders a plain text page with structured sections and placeholder values for personal data. Centered layout, max-width ~640px.

## Props

None. This is a static content page with placeholder data to be filled in by the operator.

## Callback Props

None.

## Content Sections

1. **Information according to SS 5 TMG** -- Name, address (placeholder)
2. **Contact** -- Email, phone (placeholder)
3. **Liability Disclaimer** -- Standard liability notices for content and links
4. **Copyright** -- Copyright notice
