# About Me

## Overview

Personal page of the operator Timo. Tells the story behind Fahrrad Wetter -- why the app was built, who is behind it, and invites community participation. Uses an authentic, personal tone with no corporate language. Centered layout, max-width ~640px.

## User Flows

1. **Read Story:** User navigates to "About Me" via navigation or footer and reads the personal story.
2. **Contact CTA:** User finds a call-to-action at the bottom linking to the contact page (`/contact`).

## Components Provided

### `AboutMe`

The complete about page component. Renders a personal hero element with name and introduction, "The Story" section, "Who is this for?" section, and a feedback CTA linking to the contact page.

## Props

None. This is a static content page. All text content is embedded in the component.

## Callback Props

None. The CTA link to `/contact` is a standard anchor/router link, not a callback.

## Content Sections

1. **Hero** -- Name "Timo" and short introduction
2. **The Story** -- Motivation: tired of checking weather apps and still dressing wrong
3. **Who is this for?** -- Beginners, casual riders, bikepackers
4. **Get Involved** -- Feedback welcome, link to contact page
