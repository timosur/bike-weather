# Tailwind Color Configuration

## Color Choices

- **Primary:** `emerald` — Used for buttons, links, key accents, active navigation states
- **Secondary:** `amber` — Used for warning badges, affiliate "Ad" labels, highlights
- **Neutral:** `stone` — Used for backgrounds, text, borders, cards

## Usage Examples

Primary button: `bg-emerald-600 hover:bg-emerald-700 text-white`
Secondary badge: `bg-amber-100 text-amber-800 dark:bg-amber-900/40 dark:text-amber-400`
Neutral text: `text-stone-600 dark:text-stone-400`
Card: `bg-white dark:bg-stone-900 ring-1 ring-stone-200 dark:ring-stone-800`
Active nav: `text-emerald-600 dark:text-emerald-400 bg-emerald-50 dark:bg-emerald-900`
