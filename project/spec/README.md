# Specification Documents

High-level technical and functional specification for the Bike Weather application.

These documents are generated and maintained by the `spec-docs` Copilot skill. They provide persistent context about the application's architecture, API, data models, features, and auth flow.

## Files

| File | Description |
|------|-------------|
| `architecture.md` | System overview, service boundaries, infrastructure |
| `api.md` | API endpoint inventory |
| `data-models.md` | ORM models and relationships |
| `features.md` | User-facing feature list |
| `auth-flow.md` | Authentication and authorization flow |

## Updating

Run the `spec-docs` skill in Copilot CLI to regenerate or update these files:

> "update spec" / "refresh docs" / "generate spec"

The skill reads the actual codebase and updates the docs to reflect current state.
